
 Academic Admin Tools

This organization contains small, practical tools designed to support academic administration.

The focus is not on “software for software’s sake,” but on building transparent, repeatable systems for tasks that recur every semester and are often handled manually through spreadsheets, emails, and institutional memory.

## What you’ll find here

Projects in this organization typically:
- Clean and normalize institutional data (e.g., enrollment, section tallies)
- Make decision logic explicit and visible
- Reduce repetitive administrative labor
- Support chairs, faculty, and administrators with clear outputs

## Current projects

- **Section Tally Cleaner**
  - A Streamlit app that cleans and standardizes section tally spreadsheets for reporting and analysis

Additional tools will be added over time as workflows are formalized.

## About

These tools are developed from the perspective of academic administration, with attention to clarity, sustainability, and real institutional constraints.
